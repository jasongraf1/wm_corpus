# Custom pronunciation entries for West Midlands / Birmingham / Black Country English.
# MFA doesn't work with commented files, so we need to convert these to a simple version.
# 1. Convert these to the basic MFA dictionary with:
#   > python 06_make_mfa_dict.py
#
# 2. Then run:
#   > mfa model download dictionary english_uk_mfa
#   > mfa model add_words english_uk_mfa custom_pronunciations_mfa.txt
#
# Format: WORD  PHONEME1 PHONEME2 ...
# Uses MFA's English MFA phoneset (based on IPA-ish labels).
# Run `mfa model inspect english_uk_mfa` to see all available phoneme symbols.
#
# NOTES:
# - These cover non-rhotic pronunciations (no /r/ post-vocalically),
#   and common West Midlands vowel realisations.
# - For velar nasal plus words, we provide BOTH pronunciations (with and without /g/)
#   so MFA can choose the best path during alignment.
# - Common th-fronting variants are included so MFA can align /f/ and /v/ realisations.
# - Glottal /t/ is not included
#
